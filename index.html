1. BPW34 Light Sensor

Adjust the simulated illuminance. The model maps 0–10,000 lux to the specified sensor voltage range of 1.7–320 mV.

Sensor voltage 160.85 mV
Conditioned voltage 0.50 V

The buffer reduces loading. The scaling amplifier has a gain of 3.125, making 320 mV approximately 1 V.

2. FPGA Gain Selection

Automatic mode uses the conditioned voltage to select one of four gain settings. Manual mode lets you test each setting.

FPGA select lines SEL0=1, SEL1=0
Selected gain 3×
VGA fixed input 0.50 V
Ideal VGA output 1.50 V
Output status Within range

SEL0/SEL1 codes are 00, 10, 01 and 11, respectively, for gains 1.5×, 3×, 4.5× and 6×.
